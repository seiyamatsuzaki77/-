# CREATOR'ZZ アフィリエイトプログラム 概要(ドラフト)

オーガニック施策の一環として、CREATOR'ZZの世界観・ターゲット層と親和性の高いクリエイターに、成果報酬型のアフィリエイト(紹介)パートナーになってもらうための企画書。

---

## 1. 目的

- 広告費をかけずに、クリエイター経由でLINE公式登録者(見込み顧客)を増やす
- CREATOR'ZZの主張(「ツールではなく構成力・マーケ視点で差がつく」)に共感するクリエイターを味方につけ、口コミ的にブランドを広げる
- 成果報酬型にすることで、初期コストゼロでテストできる

## 2. 報酬条件

| 項目 | 内容 |
|---|---|
| 報酬形態 | 成果報酬(生徒紹介) |
| 発生条件 | 紹介経由で入学した生徒が、入学から**1ヶ月経過した時点**で報酬確定(全額返金保証期間が1ヶ月あるため、その期間経過をもって「成約」とする) |
| 単価 | **1件あたり 15万円(税込)** |
| 支払サイト | 例:報酬確定(入学1ヶ月経過)月の翌月末払い ※要確定 |
| 支払方法 | 銀行振込(振込手数料の負担者を明記) |
| 上限 | 特になし/上限を設ける場合は要検討 |

※「成約」= 紹介経由の生徒が入学し、全額返金保証期間(1ヶ月)を経過して退会・返金がなかった時点。この定義はすでに確定済み。

## 3. トラッキング方法(要確定)

成果を正しく紐付けるために、以下のいずれかを用意する必要がある。

- クリエイターごとの固有LINE登録リンク(トラッキングパラメータ付きURL)
- クリエイター専用のクーポンコード/紹介コード(申込フォームで入力してもらう)
- 「〇〇さんの紹介です」の自己申告 + 簡易チェック(小規模運用ならこれでも可)

## 4. 対象クリエイターの条件(ターゲットプロファイル)

- X(旧Twitter)またはInstagramで一定のアクティブなフォロワーを持つ
- AI動画生成ツール(Seedance, Runway, Kling, Vidu, Pikaなど)、動画編集、コンテンツマーケティング、クリエイターエコノミー関連の発信をしている
- 「ツールを使いこなす」だけでなく「構成・マーケ視点」に関心・共感がありそうな発信スタイル
- フォロワーの質(エンゲージメント率)を重視。フォロワー数だけで選ばない

## 5. 提供する情報・アセット(パートナー向け)

- 紹介用リンク/コード
- 投稿・DM用の紹介文テンプレート(別紙)
- CREATOR'ZZの実績・数値(あれば)
- バナー/サムネイル素材(あれば)

## 6. 進め方(ドラフト)

1. 候補クリエイターをリストアップ(別紙)
2. DMで打診(別紙テンプレート使用)
3. 興味を持ってもらえたら、条件詳細・トラッキング方法をすり合わせ
4. 合意後、紹介リンク/コードを発行してスタート
5. 定期的に成果・支払いを確認

---

**要確定事項(社内で先に決めておくべきこと)**
- 支払サイト・振込手数料負担
- トラッキング方法の実装可否(誰がリンク発行するか)
- 契約書/覚書が必要か(15万円/件の金額感だと簡易契約書を交わすのが望ましい)
- インボイス対応(相手が事業者かどうかで源泉徴収・請求書の扱いが変わる)
- 入学後1ヶ月時点で「返金なし」をどう確認・突合するフローにするか(生徒管理側との連携)
