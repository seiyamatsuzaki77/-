# CREATOR'ZZ アフィリエイトプログラム 承認依頼(小澤さん向け)

## 1. 概要

CREATOR'ZZのオーガニック施策として、AI動画・クリエイター系の発信者に成果報酬型のアフィリエイトパートナーになってもらい、LINE公式登録者(見込み顧客)を広告費ゼロで増やす施策。

- 報酬形態:成果報酬・生徒紹介ベース
- 単価:紹介経由の入学1件につき **15万円(税込)**、入学から1ヶ月経過(全額返金保証期間の満了)をもって報酬確定
- 進め方:まず15名に打診 → 反応を見て条件・文面を調整 → 良ければ拡大

詳細は `affiliate-program-overview.md`(条件詳細)、`affiliate-dm-templates.md`(打診文面)、`affiliate-creator-candidates.md`(候補者リスト)を参照。

---

## 2. なぜ15万円(税込)・入学1ヶ月経過後確定なのか

### (1)ROIから見た妥当性

成果報酬型なので、そもそも入学が発生しない限りコストは発生しない。さらに支払いタイミングを「入学1ヶ月経過後」にすることで、全額返金保証期間内の解約・返金リスクを会社側が負わずに済む。
つまり広告費のような「投下してから成果が出るか賭ける」タイプの投資ではなく、**返金リスクも織り込み済みの、実質ノーリスクなCAC(顧客獲得コスト)**。
15万円という単価は、CREATOR'ZZ側のバックエンド商品・サービスの単価/LTVに対して十分ペイする範囲で設定(※バックエンド単価との比較値は要記入。例:バックエンド商品が◯◯万円であれば、CAC比率は◯%で健全な範囲)。

### (2)クリエイターに"本気で動いてもらう"ための金額設計

- 5万円・10万円だと「ついでに一回投稿してみるか」程度の温度感で終わりやすい。
- 15万円という金額は、クリエイター側にとっても「これは本気で紹介先の質を考えよう」「DMも丁寧にやろう」と思わせる閾値になりうる。
- 特にマイクロ〜ミドル層のクリエイターにとって、1件の紹介で15万円は、通常の単発PR案件(数万円〜十数万円程度が相場と言われる)よりも高く、「広告案件を受けるより、これを本気で紹介した方が割がいい」という比較優位を作れる。

### (3)"成果報酬"という構造そのものが信頼を生む

固定のPR案件と違い、成果報酬は「本当に良いものだから紹介する」という文脈を作りやすく、クリエイターの発信スタイル・フォロワーとの信頼関係を壊しにくい。金額を高めに設定することで、この文脈をクリエイターに"やる価値がある"と感じてもらいやすくする狙いがある。

### (4)固定額(%ではない)にするメリット

- 定率(例:入学金額の20%)にすると、クリエイター側が「結局いくら貰えるのか」を都度計算する必要があり、訴求力・分かりやすさで劣る。
- 「1件15万円」という即答できる金額の方が、DMでの初回訴求・意思決定のハードルを下げやすい。

### (5)「入学1ヶ月経過後に確定」という支払いタイミングの合理性

- CREATOR'ZZ側に生徒への全額返金保証期間(1ヶ月)があるため、その期間中に返金となった案件にまで報酬を払うと、会社側が二重に損失を負う(返金 + 紹介報酬)構造になってしまう。
- 「保証期間満了 = 実質的に成約が確定した」タイミングでの支払いは、会社・クリエイター双方にとってフェアな基準になる。
- クリエイターにも「紹介して終わり」ではなく、紹介した生徒が続けられるかどうかまで意識してもらえる(質の高い紹介を促すインセンティブにもなる)。

> ※上記の根拠づけをより強くするには、以下の実数があると説得力が増します(社内で把握していれば追記推奨)
> - CREATOR'ZZバックエンド商品の平均単価・LTV
> - 現状の広告経由CAC(比較対象があると「広告よりアフィリエイトの方が効率的」と言い切れる)
> - 過去のPR案件・インフルエンサー起用実績があれば、その単価相場
> - 全額返金保証期間中の解約率(実績があれば、1ヶ月確定という設計の妥当性をさらに補強できる)

## 3. 進め方(スモールスタート案)

1. **第1弾:15名に打診**(候補リスト:`affiliate-creator-candidates.md` の確認済み6件 + note経由5件の本人アカウントを特定した上で拡充し、15名を確定)
2. DMテンプレート(3パターン)を使い分けてA/Bテスト的に打診し、返信率・温度感を記録
3. 反応が悪い場合の想定改善パターン:
   - 金額は変えず、文面・アプローチ(共感ポイントの個別化)を先に見直す
   - 業界相場と比較して金額が低いと感じられていそうであれば単価見直しを検討
   - トラッキング方法(専用リンク/コード)への不安・手間感が障壁なら、運用側でハードルを下げる
4. 数名でも成約実績が出たら、その実績を次のDM打診時の"社会的証明"として活用し、候補を拡大

## 4. リスク・懸念事項(承認判断のために)

- **トラッキングの正確性**:専用リンク/コードの発行運用が未整備。誰がどう発行・管理するかを決める必要あり
- **契約関係**:1件15万円という金額感だと、口頭合意ではなく簡易的な業務委託契約書/覚書を交わすのが望ましい(インボイス・源泉徴収の扱いも要確認)
- **入学1ヶ月後確認フローの整備**:紹介経由の生徒が「1ヶ月時点で継続中(返金なし)」かどうかを、生徒管理側とどう突合するかの運用を決める必要あり
- **予算上限**:今回は「入学1ヶ月後の後払い」なのでキャッシュアウトのタイミングリスクは低いが、同時多発的に確定が重なった場合の月間支払い上限や資金繰りへの影響は事前に確認しておきたい
