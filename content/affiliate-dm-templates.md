# CREATOR'ZZ アフィリエイト打診 DMテンプレート(ドラフト)

対象:X(旧Twitter)/Instagramで、AI動画生成・動画編集・クリエイター向けマーケティング関連の発信をしているクリエイター。
トーン:CREATOR'ZZの既存コンテンツ(「Seedance 2.5は凄い。でも、お前は凄くない。」)に近い、率直・本質重視のトーン。ただしDMは初対面なので、そこまで挑発的にせず「敬意 + 本題を明確に」を優先。

---

## テンプレートA:初回DM(短め・カジュアル)

```
はじめまして、CREATOR'ZZ運営の〇〇と申します。

普段の投稿、拝見しています。
AI動画ツールの使い方だけでなく「何のために作るか」という視点まで発信されているところに共感し、ご連絡しました。

今回、CREATOR'ZZでは成果報酬型のアフィリエイトパートナーを募集しています。
・成果報酬(成約1件につき20万円/税込)
・広告色を出さず、ご自身の発信スタイルの中で自然に紹介いただく形でOK

もしご興味があれば、詳細資料をお送りしますので、5分だけお時間いただけないでしょうか。
```

## テンプレートB:初回DM(やや詳しめ・実績訴求込み)

```
はじめまして、CREATOR'ZZ運営の〇〇です。

AI動画生成ツールが民主化される中で「ツールではなく構成力・マーケ視点で差がつく」というテーマで発信している〇〇さんの投稿に、強く共感しました。

CREATOR'ZZは同じ問題意識のもと、AI動画時代のマーケティング視点・構成力を教えるコンテンツをLINE公式で展開しています。

このたび、成果報酬型のアフィリエイトパートナーを数名限定で募集しており、〇〇さんにぜひご検討いただきたくご連絡しました。

【条件】
・成果報酬形式(広告費の先払いなし)
・成約1件につき20万円(税込)をお支払い
・紹介方法は投稿・ストーリーズ・DM等、〇〇さんのスタイルに合わせて自由に設計可能
・専用の紹介リンク/コードを発行し、成果を正確にトラッキング

無理な宣伝トーンや、既存の発信スタイルを崩すようなお願いはしません。
もしご興味があれば、資料と条件詳細をまとめてお送りしますので、一度お話しさせてください。
```

## テンプレートC:超簡潔版(返信率重視・最初の一通に)

```
〇〇さん

はじめまして、CREATOR'ZZの〇〇です。
AI動画×マーケ視点の発信、いつも興味深く拝見しています。

成果報酬(1件20万円/税込)のアフィリエイトパートナーを探しており、〇〇さんにご相談したく連絡しました。
5分だけお時間いただけそうであれば、詳細をお送りします。
```

## 運用メモ

- `〇〇` は必ず名前(アカウント名)に差し替え、投稿内容から具体的に「どこに共感したか」を一言添えると返信率が上がる(定型文だけだと埋もれる)。
- 最初のDMで金額条件を出すか迷う場合は、テンプレートCのように「金額は明記しつつ詳細は次のステップ」にすると心理的ハードルが下がる。
- 返信があった相手には、affiliate-program-overview.md の内容をベースにした詳細資料(PDF/Notion等)を送る運用を想定。
- DM送信は各プラットフォームの規約・スパム判定に注意し、一括送信ツールでの大量送信は避け、手動または少数ずつ丁寧に送ることを推奨。
